Further explanation

How shape handles work

Drag the green handles outside the wire. Top and bottom handles move vertically; the right handle moves horizontally. Corner handles change steps or indentations while keeping that preset's turns intact. The loop length changes as you resize it. Each resistor end follows its wire section, so the resistor can stretch or shrink. An end that reaches a corner moves to the nearest valid spot. A resize stops when the loop would overlap itself, components would overlap, or the loop exceeds the supported size.

About this model

Wires have finite resistance. The battery supplies a driving force inside its material. Outside potential is approximated by a distant zero-potential boundary, with net circuit charge set to zero. Corners are sharp; fields very close to them depend on mesh resolution.
